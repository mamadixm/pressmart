# 🛍️ PressMart — Modern E-Commerce Platform

یک وب‌سایت فروشگاهی مدرن، واکنش‌گرا و بهینه‌سازی‌شده برای سئو، پیاده‌سازی‌شده با جدیدترین استانداردهای Next.js (App Router).

---

### 🌟 ویژگی‌های برجسته
- **سبد خرید و لیست علاقه‌مندی‌ها:** مدیریت استیت پایدار کلاینت با Zustand و ذخیره‌سازی در LocalStorage.
- **جستجوی زنده (Live Search):** پیشنهاد آنی محصولات با تایپ هر کاراکتر در هدر.
- **صفحات داینامیک محصول:** رندر منعطف مشخصات فنی، سایزبندی، توضیحات و سیستم ثبت دیدگاه.
- **فرایند تسویه حساب (Checkout):** فرم دریافت اطلاعات گیرنده، اعتبارسنجی و شبیه‌سازی تولید کد رهگیری مرسوله.
- **معماری ماژولار صفحات محتوایی:** طراحی یکپارچه صفحات راهنما (FAQ، شرایط مرجوعی، حفظ حریم خصوصی و فرم تماس).
- **طراحی کاملاً واکنش‌گرا و راست‌چین (RTL):** سازگاری کامل با تمامی دیوایس‌ها بر پایه Tailwind CSS.

---

### 🛠️ ابزارها و تکنولوژی‌ها
- **Framework:** Next.js (App Router) + TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Zustand + Persist Middleware
- **Icons & UI:** Lucide React & Radix UI
- **Notifications:** Sonner Toast

---
